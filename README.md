# impulse-tv

Digital-signage player page for the Impulse Cameras showroom TVs (PosterBooking).

Each screen loads this page with a `?v=<vendor>` parameter. The page plays that
vendor's YouTube uploads feed full-screen next to a branded rail carrying the
Impulse logo, a QR code to that brand's page on impulsecameras.com, and QR codes
for our social accounts.

## Why this page exists

PosterBooking's URL module loads a URL **top-level** in the player. YouTube
refuses a bare `youtube.com/embed/...` request that arrives with no referrer and
returns **Error 153 — video player configuration error**. Hosting the iframe
inside a real page on a real https origin gives YouTube a valid referrer, which
is all it needs.

## Usage

    https://impulse-cameras.github.io/impulse-tv/?v=nikon

| `?v=` | Channel |
| --- | --- |
| `impulse` | **Impulse Cameras (our own channel)** |
| `nikon` | Nikon |
| `canon` | Canon |
| `sony` | Sony |
| `sigma` | SIGMA |
| `blackmagic` | Blackmagic Design |
| `shure` | Shure |
| `benro` | Benro |

### Optional parameters

| Param | Default | Effect |
| --- | --- | --- |
| `shuffle` | `1` | `0` plays newest-first instead of shuffled |
| `min` | `65` | Skip videos this many seconds or shorter (drops vertical Shorts). `0` disables |
| `reload` | `180` | Minutes between self-refreshes. `0` disables |

Ad-hoc playlist, no vendor entry needed:

    ?list=UUxxxxxxxxxxxxxxxxxxxxxx&name=Some%20Brand

## Playlist IDs

Each `list` is the channel's **uploads** playlist — the channel ID with `UC`
swapped for `UU`. It updates itself as the vendor publishes, so no maintenance.

## Robustness

- Autoplay requires `mute=1`; these screens are silent by design.
- Embed-blocked or removed videos fire `onError` and are skipped automatically.
- A 60-second watchdog reloads the page if playback never starts.
- The page self-reloads every 3 hours so a screen left on for days stays fresh.

## Editing

`index.html` is generated by `build_tv.py` (kept in the impulse-hq vault), which
inlines the logo and generates every QR code with `segno`. The page has no
external dependencies except YouTube's iframe API.
